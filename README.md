# Windows Administration Labs

This repository contains practical Windows system administration labs using PowerShell. All tasks were performed in real environments and documented for my IT Support portfolio.

## Skills Demonstrated
- Local user and group management
- Password resets and account recovery
- ACLs (DACL, SACL, ACE)
- File search and recursion
- Troubleshooting access issues
